# AGENTS

## Documentation Contracts

For documentation tasks in this repository:

- Read `.agents/docs-preset/MANIFEST.md` for the active contract registry.
- Read `.agents/docs-preset/TOOLING.md` for source format, commands, generated outputs, and edit safety.
- Read `.agents/docs-preset/STYLE.md` for voice, terminology, syntax conventions, and review criteria.
- Read `.agents/docs-preset/STRUCTURE.md` for documentation surfaces, zones, and placement rules.

Apply sources in this order:

1. User request.
2. Local repository rules.
3. The documentation contracts above.

When you edit user-facing docs:

- Preserve the existing source format and repo conventions.
- Do not edit generated outputs or locked files.
- Mark verification gaps instead of inventing product facts.
